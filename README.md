# Calculadora de abono de permanência

Estimativa das parcelas de 13º e terço de férias sobre o abono de permanência (Tema 1.233 do STJ).

Página estática. Os índices IPCA-E e SELIC são lidos no navegador, na API do Banco Central.

Publicação: https://williansantosadvocacia-png.github.io/calculadora-abono/
